# 创意方法论库

使用方式：先判断策略要解决哪种传递问题，再选择对应思考流派。不要把方法论当成点子列表；它们的作用是把策略变成客户和消费者能理解、相信、记住、转述、行动的表达。

## 一、流派选择

| 传递难点 | 优先流派 | 适合解决的问题 |
|---|---|---|
| 消费者记不住 | 华与华 | 把策略变成超级符号、超级话语、购买理由 |
| 创意角度太平 | 奥美/Deck of Brilliance | 从 52 个角度重新解释策略，找到更有冲突和记忆点的表达 |
| 客户不买单 | 麦肯锡 | 用结论先行、证据链、MECE 结构说服决策人 |
| 品牌想有更大意义 | 群玉山 | 把品牌放进公共叙事、社会角色、时代情绪 |
| 平台传播分散 | 组合使用 | 用一个核心策略，生成不同平台的表达方式 |

## 二、华与华式思考

华与华适合把策略变成可被看见、说出、转述、购买的符号系统。

### 方法卡

| 方法 | 怎么用 | 输出检查 |
|---|---|---|
| 超级符号 | 借用用户本来就熟悉的文化符号、动作、声音、颜色或图形 | 用户一眼能懂，不需要解释 |
| 超级话语 | 把策略写成口语化、行动化、容易复述的话 | 像俗语、吆喝或购买指令，而不是文艺句子 |
| 购买理由 | 回答“为什么现在买、为什么买你” | 能落到产品、场景、利益或信任背书 |
| 货架思维 | 在真实购买现场判断表达是否有效 | 包装、陈列、标题、主视觉能否一秒被识别 |
| 品牌寄生 | 寄生在已有文化母体上，而不是从零创造认知 | 借势节日、俗语、动作、民俗、公共经验 |
| 全部动作一件事 | 产品、包装、广告、渠道、活动都服务同一个战略动作 | 不要线上一个概念、线下另一个概念 |

### 输出模板

```markdown
## 华与华式转译
- 策略：
- 超级符号：
- 超级话语：
- 购买理由：
- 货架动作：
- 可被用户转述的一句话：
```

## 三、奥美 / Deck of Brilliance 式思考

公开资料显示，Deck of Brilliance 最初以 52 个创意工具卡帮助创意人从不同角度进入问题；群玉山分享中提到它由 Juggi Ramakrishnan 和 Todd McCracken 创造，并举过“戏剧化描述问题”“交换角色”“树立敌人”等例子。以下是面向中文广告提案实操整理的 52 张工作卡，不逐字复刻官方卡牌。

### 52 张策略解释卡

| # | 方法卡 | 用法 |
|---:|---|---|
| 1 | 戏剧化问题 | 把策略要解决的问题拍得更夸张、更可感 |
| 2 | 交换角色 | 让产品、用户、问题、旁观者互换位置 |
| 3 | 树立敌人 | 定义品牌反对什么，让立场更清晰 |
| 4 | 世界没有它 | 展示没有产品/品牌时世界会怎样 |
| 5 | 夸大后果 | 把一个小痛点放大到难以忽视 |
| 6 | 缩小到动作 | 把大策略压缩成一个动作或瞬间 |
| 7 | 视觉隐喻 | 用一个画面解释抽象策略 |
| 8 | 声音符号 | 用声音、节奏、口头禅建立记忆 |
| 9 | 反转常识 | 让用户发现“原来不是 A，而是 B” |
| 10 | 错置场景 | 把产品放进意外场景，制造新理解 |
| 11 | 拟人化 | 让产品像一个角色一样行动和表达 |
| 12 | 用户自白 | 让用户说出品牌不适合自夸的话 |
| 13 | 第三者证明 | 让朋友、同事、家人、路人来证明价值 |
| 14 | 前后对照 | 展示使用前后的状态变化 |
| 15 | 失败版本 | 展示不用它、用错它、失去它会怎样 |
| 16 | 最后一刻 | 把策略放进最紧张或最需要的瞬间 |
| 17 | 第一反应 | 抓住用户第一次看到/听到/尝到的反应 |
| 18 | 隐藏真相 | 揭开一个用户没意识到的事实 |
| 19 | 文化挪用 | 借用流行文化、节日、梗、仪式解释策略 |
| 20 | 旧词新解 | 重新解释行业常用词 |
| 21 | 制造仪式 | 把使用行为设计成重复动作 |
| 22 | 设计口头禅 | 让策略能被用户一句话说出去 |
| 23 | 建立阵营 | 让用户觉得“这是我们这种人的选择” |
| 24 | 反派视角 | 从问题、竞品或阻力的视角讲品牌价值 |
| 25 | 极端用户 | 用最极端的人群说明核心利益 |
| 26 | 极端场景 | 把产品放到最需要它的情境 |
| 27 | 类比迁移 | 用另一个熟悉行业解释当前策略 |
| 28 | 小题大做 | 把小产品点讲成大的生活问题 |
| 29 | 大题小做 | 把宏大价值落到微小动作 |
| 30 | 反差组合 | 把两个看似无关的事物强行连接 |
| 31 | 时间跳跃 | 从过去/未来看现在的策略价值 |
| 32 | 物件证言 | 让包装、道具、票据、桌面替人说话 |
| 33 | 空间占领 | 让品牌成为一个场所的默认组成 |
| 34 | 数据变形 | 把数据翻译成画面、动作或故事 |
| 35 | 规则改写 | 改写一个场景里的默认规则 |
| 36 | 禁忌说出 | 说出用户不方便承认的真实动机 |
| 37 | 情绪命名 | 给一种模糊情绪命名 |
| 38 | 集体记忆 | 调动一代人共同经历 |
| 39 | 关系触发 | 用朋友、情侣、亲子、同事关系解释策略 |
| 40 | 对手借力 | 借竞品或行业惯性反衬自己 |
| 41 | 证明任务 | 设计一个用户可参与的证明动作 |
| 42 | 连续剧结构 | 把策略拆成系列内容，而非单支广告 |
| 43 | 反证法 | 先证明旧方法不成立，再推出品牌方案 |
| 44 | 用户误会 | 从用户误解进入，再纠正认知 |
| 45 | 入口变换 | 从购买、使用、分享、复购中换入口 |
| 46 | 语言错位 | 用另一类语言体系讲这个产品 |
| 47 | 行为可视化 | 把看不见的心理变化变成行为 |
| 48 | 参与门槛 | 设计一个用户容易模仿的低门槛动作 |
| 49 | 情绪升温 | 让内容从平静到爆发逐步递进 |
| 50 | 价值冲突 | 让两个都对的价值发生冲突 |
| 51 | 反向承诺 | 不承诺更多，而承诺少一点、更精准一点 |
| 52 | 一句话统领 | 用一句核心创意统领所有文案和画面 |

### 输出模板

```markdown
## 奥美式创意解释
| 方法卡 | 如何解释策略 | 可能的内容形式 | 风险 |
```

## 四、麦肯锡式思考

麦肯锡式方法适合把策略变成客户愿意买单的商业逻辑。重点不是“创意好不好玩”，而是“结论是否清楚、证据是否充分、推演是否不重不漏”。

### 方法卡

| 方法 | 怎么用 | 输出检查 |
|---|---|---|
| 结论先行 | 先说建议客户做什么，再解释为什么 | 第一页就能看懂主张 |
| SCQA | 情境、冲突、问题、答案 | 开场有张力，不是平铺背景 |
| MECE | 拆解不重不漏 | 场景/人群/渠道/问题不要互相重叠 |
| 议题树 | 把大问题拆成可回答的小问题 | 每个问题都能被资料或判断回答 |
| 证据链 | 每个主张后面有事实、案例或数据 | 不靠形容词说服客户 |
| 行动标题 | 每页标题就是一个判断 | 只读标题能读懂整套提案 |

### 输出模板

```markdown
## 麦肯锡式策略说服
- 结论：
- SCQA：
- MECE 拆解：
- 证据链：
- 客户要采取的动作：
```

## 五、群玉山式公共叙事

群玉山式方法适合把品牌从卖点传播提升到社会角色与公共叙事。公开访谈中，群玉山强调为中国品牌塑造社会公共角色、在全球语境下讲中国故事与中国价值观。用它时要避免空喊价值观，必须回到产品和真实行动。

### 方法卡

| 方法 | 怎么用 | 输出检查 |
|---|---|---|
| 社会公共角色 | 品牌在社会中承担什么角色 | 不是“品牌想说什么”，而是“社会需要它做什么” |
| 时代情绪 | 捕捉一代人的共同情绪 | 情绪要具体，不要空泛正能量 |
| 公共议题入口 | 从城市、家庭、劳动、代际、性别、健康等议题进入 | 议题必须和产品行动有关 |
| 小人物叙事 | 用普通人的故事承载大命题 | 人物不能只是价值观道具 |
| 中国经验 | 从本土生活、文化和现实关系里找表达 | 避免生硬国潮符号 |
| 长线品牌志向 | 说明品牌长期想为行业/社会留下些什么 | 不能只有一波 campaign 的热闹 |

### 输出模板

```markdown
## 群玉山式公共叙事
- 品牌公共角色：
- 对应时代情绪：
- 可讲的小人物故事：
- 品牌真实行动：
- 适合/不适合的原因：
```
