# 风格方法库

使用方式：选择最适合客户和提案场景的风格路径。目标是提炼推演方式，不是复制页面外观。

## 麦肯锡式结构化表达

- 适用：国际客户、B2B、高客单、战略咨询、管理层汇报。
- 核心：先结论、后论证；图表服务判断；页面信息密度高但层级清楚。
- 视觉：白底/浅灰、克制色彩、数据图表、标题结论化。
- 禁区：空洞大图、情绪化标题、无证据金句。

## 华与华式符号化

- 适用：本土消费品牌、连锁、下沉市场、需要快速记忆的传播。
- 核心：把品牌战略变成符号、口号、动作和购买理由。
- 视觉：强符号、强对比、简单重复、可落地到包装/门店/广告。
- 禁区：只模仿红黄大字，不解释符号为什么成立。

## 叶茂中式冲突定位

- 适用：品类竞争激烈、消费者选择犹豫、需要快速建立购买理由。
- 核心：找到消费冲突，并让品牌成为解决冲突的选择。
- 视觉：强冲突标题、对比图、问题-解决方案结构。
- 禁区：制造不存在的冲突，或把冲突写成情绪口号。

## 创意热店式情绪放大

- 适用：快消、年轻化品牌、社媒传播、话题 campaign。
- 核心：把人群情绪、反差和文化语境放大成传播事件。
- 视觉：更大胆的图像、强标题、反差场景、社交内容感。
- 禁区：只有“炸”的形式，没有策略承接。

## 社会公众角色叙事

- 适用：公益、城市、教育、医疗、ESG、公共议题、企业形象。
- 核心：让品牌承担一个社会角色，回应公众情绪或时代问题。
- 视觉：纪实感、人群故事、场景证据、克制但有温度。
- 禁区：把社会议题工具化，或空喊价值观。

## 选择规则

- 老板/本土企业：优先符号化、冲突定位。
- 外企/咨询型客户：优先结构化表达。
- 年轻消费品牌：优先情绪放大、符号化。
- 公共议题：优先社会公众角色叙事。
- 内部汇报：优先结构化表达，降低创意化视觉。
