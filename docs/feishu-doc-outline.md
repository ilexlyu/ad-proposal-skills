# 飞书说明文档大纲

标题：广告提案 Agent Skills：从模糊 Brief 到完整提案工作流

## 开头

这是一套面向广告新人、策略/创意/内容团队的 Agent Skills。它解决的不是“更快生成 PPT”，而是把一个模糊 brief 拆成可判断、可表达、可交付的提案流程。

GitHub：https://github.com/ilexlyu/ad-proposal-skills

飞书：https://my.feishu.cn/docx/Q95Sdsj30oEwLOxxpMDci6mKnHd

## 总流程

Brief → 资料 → 洞察 → 创意 → 结构 → 视觉 → 复盘

## 7 个 Skill

| Skill | 作用 |
|---|---|
| 提案总控 | 拆 brief，判断缺失信息和调用顺序 |
| 行业资料搜集 | 建立带来源和可信度的资料表 |
| 洞察生成评审 | 把事实改写成有判断的策略句 |
| 创意方法论 | 用华与华、奥美、麦肯锡、群玉山解释策略 |
| 提案结构叙事 | 生成客户听得懂的 PPT 主线和逐页蓝图 |
| PPT 视觉架构 | 把模糊视觉词翻译成页面规则和设计交接稿 |
| 交付质检复盘 | 检查风险，沉淀下次可复用资产 |

## 安装方式

```bash
git clone https://github.com/ilexlyu/ad-proposal-skills.git
cp -R ad-proposal-skills/skills/ad-* ~/.codex/skills/
```

重新打开 Codex / Agent 后，使用：

```text
Use $ad-proposal-orchestrator
```
